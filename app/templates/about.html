THE STORY BEHIND THE PROJECT

Built to learn. Designed to explain.

A complete portfolio project connecting machine learning with a useful web experience.

From a dataset to a working application

DiabetesAI is an educational project by AliAdilQ. It shows how to build a reproducible machine learning workflow, validate input, serve predictions through Flask, and manage records in a protected analytics workspace.

The eight input features follow the schema commonly used in Pima-style diabetes classification exercises. All bundled values and labels are generated synthetically. The project contains no clinical records and makes no clinical claims.

github.com/AliAdilQ/diabetes_risk_prediction

Learning has limits

Performance on synthetic data measures how well a model learns an invented rule. It does not demonstrate performance on real people. This demo does not account for measurement context, population differences, or clinical assessment, and probabilities are not clinically calibrated.
